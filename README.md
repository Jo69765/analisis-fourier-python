# Simulación de Señales y Análisis con Transformada de Fourier

Repositorio académico que contiene la implementación en Python para el modelado de señales en el dominio del tiempo y su respectivo análisis espectral mediante la Transformada Rápida de Fourier (FFT).

## Descripción del Proyecto
El script simula una señal compuesta por dos componentes senoidales de 50 Hz y 120 Hz con una frecuencia de muestreo de 1000 Hz. Posteriormente, aplica la librería NumPy para calcular la FFT y visualizar tanto la forma de onda temporal como el espectro de frecuencias exacto.

## Requisitos del Sistema
Para ejecutar correctamente el script, es necesario tener instalado Python 3.x junto con las siguientes librerías científicas:
- numpy
- matplotlib

Puedes instalar las dependencias ejecutando el siguiente comando en tu terminal:
pip install numpy matplotlib

## Instrucciones de Ejecución
1. Clona o descarga este repositorio en tu computadora.
2. Abre el archivo analisis_fourier.py en tu entorno de desarrollo preferido (como Visual Studio Code).
3. Ejecuta el script para generar las ventanas gráficas con los resultados del dominio del tiempo y de la frecuencia.
